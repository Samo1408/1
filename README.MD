** اسم التطبيق My Repo **
** github.myrepo.alltools حزمة التطبيق **

** الفكرة من التطبيق الوصول الكامل الى حساب github باستخدام واجهة تسجيل دخول عن طريق PAT Token الخاص بحساب جيت. هاب **

** الواجهة الأولى عبارة عن خانة Enter PAT Token To Login وزر الدخول **

** ننتقل الى الواجهة الرئيسية بعد تسجيل الدخول **

** يتم التعامل مع كل الأوامر التالية عن طريق سكربتات بايثون لسهولة التعامل مع الموقع **

** على اليسار في الواجهة الرئيسية توجد 3 شرطات للتفتح قائمة منبثقة جانبية يظهر من خلالها Repositories - Commands - Settings **

** عند الضغط على Repositories يتم اظهار المستودعات الموجودة على حساب جيت هاب المتصل تظهر على واجهة التطبيق الرئيسية و عند الضغط على اي مستودع يتم الدخول اليه كما لو كان الحساب مفتوح على الموقع او التطبيق **

** اضافة خيارات (New Repository - Import from git - Delete Repository - Rename Repository) تكون تفاعلية مع الحساب بشكل مباشر لاضافة او حذف او ادراج او تغيير اسم مستودع ما **

** عند الدخول الى Repository معين يتم اظهار خيارات (Add files - Create file / folder - rename file/folder - upload file/folder - download the current location as zip - Create New branch - Rename branch - delete branch) بحيث يمكنني رفع الملفات او المجلدات من ذاكرة الجهاز مباشرة الى المستودع **

** اعطاء صلاحيات الوصول إلى الملفات والاشعارات - انشاء مجلد خاص بالتطبيق تحت اسم My Repository على الذاكرة الداخلية ليتم حفظ الملفات او التنزيلات او محفوظات الاعدادات و بالنسبة للاشعارات يتم اظهار شريط تقدم الترفيع او التنزيل الحالي **

** في قائمة Commands الجانبية يتم اظهار الأوامر التي يمكن للتطبيق القيام بها و الأدوات المتوفرة و استخدامها بشكل تفاعلي داخل الواجهة او التطبيق **

** بالنسبة لقائمة Settings الجانبية تحتوي على ازرار Save PAT Token داخل مجلد التطبيق على شكل pattoken.db لاستعادته عند اللزوم - اضافة زر Login github باستخدام واجهة webview لتسجيل الدخول و الوصول الى حساب جيت هاب  اضافة زر Export/Import Cookies لحفظ بيانات المتصفح الداخلي و استعادتها عند اللزوم **

** لغة بناء التطبيق java / kotlin و بعد كتابة الكود يتم ضغطه ليتم تجربة بنائه على Android Studio /AndroidIDE **
